
# OSSEC HIDS – Security Monitoring & Incident Response Home Lab

## Project Overview

This project documents a hands-on Linux security monitoring and incident response home lab built using OSSEC HIDS (Host-based Intrusion Detection System).

The objective is to understand how security monitoring works, detect suspicious activities, monitor file integrity, analyse security alerts, and investigate potential security incidents.

## Objectives

- Understand Host-based Intrusion Detection Systems (HIDS).
- Configure security monitoring in a Linux environment.
- Monitor authentication and system logs.
- Implement File Integrity Monitoring (FIM).
- Generate and investigate security alerts.
- Understand security event analysis and incident response.
- Explore MITRE ATT&CK mappings for relevant security events.

## Tools & Technologies

- OSSEC HIDS
- Ubuntu Linux
- Linux Command Line
- File Integrity Monitoring (FIM)
- Log Analysis
- Security Event Monitoring
- MITRE ATT&CK

## Planned Project Implementation

1. Prepare the Ubuntu Linux environment.
2. Install and configure OSSEC HIDS.
3. Configure system and authentication log monitoring.
4. Enable File Integrity Monitoring.
5. Monitor a custom test directory.
6. Generate controlled security events.
7. Analyse alerts and investigate suspicious activities.
8. Document findings and incident response procedures.
