#OSSEC HIDS - Security Monitoring & Incident Response Home Lab

## Project overview

This project documents a hands-on Linux security monitoring and incident response home lab built 
using OSSEC HIDS.

The objective is to understand how security monitoring workds, detect suspicious activies, 
monitor file interfrity, analyse security alerts and incestigate potential security incidents.

##Objective

- Understand Host-based intrution detection systems.
- Configure security monitoring in a linux env.
- Monitor authentication and system logs.
- Implement file integrity monitoring.
- Genrate and investigate security alerts.


## Tools & Technologies

- OSSEC HIDS
- Ubuntu Linux
- Linux CLI
- File intergrity monitoring
- Log Analysis
- Security even monitoring
